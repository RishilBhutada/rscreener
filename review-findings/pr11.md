## Checked and not raised

- Quarter labels (`quarter`, `quarter_reported`, `quarterDue`, `quarterAfter`, `quarterBefore`) - correct for every month.
- Gold parity units (COMEX $/oz x USD/INR x 10 / 31.1035 = Rs per 10 g) and the gold/silver ratio units - correct.
- FRED headline figures (CPI and PCE m/m, payrolls change, claims and JOLTS levels, GDP annualised) - units correct; previous figure is the revised one as of release day, which is how calendars show it.
- Index P/E percentile wording ("Cheaper/Dearer than x% of 10y") - direction correct for P/E, P/B and dividend yield.
- Company-table "% change" uses points for rows ending in "%" (margins, shareholding) - correct.
- `fetch_results_history --only-missing` dates results by `revised_Date` first - same rule as `fetch_filing_dates.py`, so consistent.
- Search-index rows for indices are added only if missing, but `index.json` is rewritten by `export_json.py` earlier in the same nightly, so they stay fresh.
